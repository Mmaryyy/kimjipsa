김집사 기능 명세

기획서 v0.11에서 확정한 내용을 기능별 요구사항과 확인 시나리오로 풀어 쓴 문서입니다. 일정부터 작성하고, 재고, 장바구니, 챗봇, 가정·계정 순으로 이어갑니다.

FEATURE · 일정일정 관리·공유

부부가 한 달력을 같이 쓰되, 개인 일정은 내용을 숨길 수 있습니다. 홈 화면의 오늘 일정, 아침 요약, 챗봇 조회가 모두 이 기능의 데이터를 씁니다.

요구사항

ID 요구사항 범위
CAL-01 일정을 등록·수정·삭제할 수 있다. 입력 항목은 제목, 날짜·시간, 카테고리, 장소, 메모입니다. MVP
CAL-02 종일 일정과 여러 날에 걸친 기간 일정을 등록할 수 있다. MVP
CAL-03 일정의 기본 참석자는 “둘 다”(공유)이다. 스위치를 켜면 개인 일정으로 바뀌어 작성자만 내용을 볼 수 있다. MVP
CAL-04 배우자의 개인 일정은 상태 아이콘과 희미한 색으로만 보이고, 제목·장소·메모는 보이지 않는다. MVP
CAL-05 공유 일정은 둘 다 수정·삭제할 수 있고, 개인 일정은 작성자만 수정·삭제할 수 있다. MVP
CAL-06 기념일은 D-day로 통합한다. D-day는 매년 같은 날짜에 자동으로 반복된다. 홈 화면에는 다음 날짜까지 남은 일수가 “D-363”처럼 표시되고, 당일에는 “D-Day”로 표시된다. MVP
CAL-07 월간, 주간, 일간 세 가지 뷰를 제공한다. 홈 화면에 보일 뷰는 사용자별로 선택한다. MVP
CAL-08 카테고리를 지정하면 달력에서 색으로 구분된다. 기본 카테고리는 “{우리집 이름}”, 회사, 가족, 약속, 병원, 기타이며, 가정을 만들 때 입력한 가정 이름이 첫 카테고리 이름이 된다. 목록은 가정 단위로 추가·수정·삭제할 수 있다. MVP
CAL-09 배우자가 공유 일정을 등록하거나 변경하면 푸시와 앱 내 알림을 받는다. 개인 일정은 배우자에게 알리지 않으며, 작성자 본인은 자기 일정의 알림(CAL-10, CAL-11)만 받는다. MVP
CAL-10 매일 아침 당일 일정을 요약해서 알린다. 기본 시각은 오전 10시이고 개인 설정에서 바꿀 수 있다. MVP
CAL-11 일정마다 알림 시점을 정할 수 있고, 기본값은 시작 30분 전이다. MVP
CAL-12 일정을 삭제하려면 확인 단계를 거쳐야 한다. 삭제 버튼을 누르면 일정 제목이 적힌 확인 화면이 나오고, 확인을 눌러야 삭제된다. 챗봇에 직접 요청한 삭제에는 이 확인 화면을 거치지 않는다(BOT-07). MVP
CAL-13 홈 화면에 “다가오는 일정” 위젯을 표시할 수 있다. 월간·주간·일간 뷰와 별개로 켜고 끌 수 있고, 일정이 있는 날짜만 날짜별로 묶어, 시작이 가까운 순서로 일정 몇 개를 보여 준다. 각 줄에는 시간, 제목, 카테고리 색이 나온다. 표시 개수는 사용자가 정한다. 별도의 어젠다(목록) 뷰는 두지 않고 이 위젯이 그 역할을 맡는다. 표시 개수는 3개, 5개, 10개 중에서 고르고 기본은 5개이다. D-day도 위젯에 포함한다. MVP
CAL-14 반복 일정(매일, 매주, 매월, 매년)을 등록할 수 있다. 반복 일정을 수정하거나 삭제할 때는 “이 일정만”과 “이후 모든 일정” 중에서 고른다. M3
CAL-15 구글 캘린더의 일정을 읽어 오고, 이 서비스에서 만든 일정을 구글 캘린더에 쓸 수 있다. 범위에서 제외했다(2026-10-30 사용자 결정). 제외
CAL-16 D-day를 등록할 때 종류를 “일반”과 “축하(celebrate)” 중에서 고른다. 축하 D-day는 당일 홈 화면에 별도의 축하 화면 요소가 나타나고, 등록한 날짜의 연도를 기준으로 몇 주년인지 함께 표시한다. 등록한 해와 같은 해에는 주년을 표시하지 않는다. MVP

기획서의 마일스톤을 따르면 반복 일정은 M3입니다. 구글 캘린더 연동(CAL-15)은 2026-10-30에 범위에서 제외했습니다.

프라이버시 규칙

  • 개인 일정의 제목, 장소, 메모는 화면과 챗봇 응답 어디에도 배우자에게 나가지 않습니다.
  • 숨김은 화면에서 가리는 것으로 끝내지 않고, 서버가 요청자 권한으로 데이터를 걸러서 내려보냅니다. 배우자의 브라우저에는 숨긴 값이 전달되지 않습니다.
  • 챗봇이 일정을 조회할 때도 질문한 사람의 권한으로 같은 필터를 거칩니다.
  • 배우자에게는 “그 시간에 일정이 있음”만 보이므로, 충돌 확인과 선제 제안은 시간 정보까지만 사용할 수 있습니다.

확인 시나리오

SCN-CAL-1 · 기본 공유일정을 만들고 참석자를 바꾸지 않으면 “둘 다”로 저장된다. 배우자의 달력에 같은 제목으로 바로 나타나고 배우자에게 알림이 간다.
SCN-CAL-2 · 개인 전환일정 등록 중 개인 스위치를 켜고 저장하면, 배우자의 달력에는 제목 없이 희미한 칸만 보인다. 배우자가 그 칸을 눌러도 상세는 열리지 않는다.
SCN-CAL-3 · 편집 권한배우자가 만든 개인 일정에는 수정·삭제 버튼이 나타나지 않는다. 공유 일정은 어느 쪽이든 수정하면 상대에게 변경 알림이 간다.
SCN-CAL-4 · 챗봇 필터배우자의 개인 일정이 있는 시간에 대해 “내일 오후 3시에 뭐 있어?”라고 물으면, 챗봇은 배우자의 개인 일정이 등록되어 있다는 사실만 알리고 제목과 장소는 말하지 않는다.
SCN-CAL-5 · 기본 알림시작 시각이 오후 2시인 일정에 알림을 따로 설정하지 않으면 오후 1시 30분에 알림이 간다. 일정별로 시점을 바꾸면 그 일정에만 적용된다.
SCN-CAL-6 · 아침 요약오전 10시에 오늘 일정이 시간순으로 한 건의 알림으로 묶여 온다. 오늘 일정이 없으면 요약 알림을 보내지 않는다.
SCN-CAL-7 · 삭제 확인일정 상세에서 삭제를 누르면 “‘제목’ 일정을 삭제할까요?”라는 확인 화면이 나온다. 취소하면 일정이 그대로 남고, 확인을 눌러야 삭제되며 공유 일정이면 배우자에게 삭제 알림이 간다.
SCN-CAL-8 · 다가오는 일정 위젯위젯 개수를 5개로 두면, 지금 이후 시작하는 일정이 날짜별로 묶여 가까운 순서로 5개 나온다. 일정이 없는 날짜는 건너뛴다. 진행 중인 기간 일정이 있으면 맨 위에 표시된다. 배우자의 개인 일정은 제목 없이 희미하게 표시된다.
SCN-CAL-9 · 기념일 반복오늘이 10월 13일이고 10월 11일을 D-day로 등록했다면, 지난 날짜가 아니라 다음 해 10월 11일을 기준으로 홈 화면에 “D-363”이 표시된다. 해가 바뀌어도 같은 날짜로 계속 반복된다.
SCN-CAL-10 · 축하 D-dayD-day를 “축하” 종류로 등록하면, 해당 날짜 당일에 홈 화면 맨 위에 축하 카드가 나타난다. 2026년 10월 11일로 등록한 축하 D-day는 2027년 10월 11일에 “1주년” 문구와 함께 나타난다. 카드를 닫으면 그날은 다시 나타나지 않고, 다음 해 같은 날 다시 나타난다.

확정한 세부 정책

  • 기념일은 D-day로 통합합니다. D-day는 매년 자동으로 반복하고, 다음 날짜까지 남은 일수를 “D-363” 형식으로 표시합니다.
  • D-day 종류는 일반과 축하(celebrate) 두 가지입니다. 축하 D-day는 당일 홈 화면에 별도의 축하 UI를 보여 줍니다.
  • 위젯 표시 개수는 3개, 5개, 10개 중에서 고르고 기본은 5개입니다. D-day도 위젯에 포함합니다.
  • 개인 일정의 알림은 작성자에게만 보냅니다.
  • 반복 일정(M3)은 수정·삭제 때 “이 일정만”과 “이후 모든 일정” 중에서 고릅니다.

축하 D-day 화면

  • 표시 시점은 당일 하루입니다. 홈 화면 맨 위에 축하 카드가 나타나고 제목, 축하 문구, 색종이 효과가 들어갑니다.
  • 다가오는 동안(D-7부터)은 위젯에서 해당 D-day 줄을 강조해서 보여 줍니다.
  • 시스템에서 “동작 줄이기”를 켠 사용자에게는 색종이 움직임 없이 카드만 보여 줍니다.
  • 축하 카드는 사용자가 닫을 수 있고, 닫으면 그날은 다시 나타나지 않습니다.
  • 카드에는 기준 연도로 계산한 “N주년”이 함께 나옵니다. 등록한 해와 같은 해에는 표시하지 않습니다.
  • 축하 문구는 기본 문구를 쓰고, D-day마다 직접 고쳐 쓸 수 있습니다.

FEATURE · 재고재고 관리

집에 무엇이 얼마나 있는지 부부가 같이 보고, 부족하거나 유통기한이 가까운 품목을 홈 화면에서 알아보는 기능입니다. 푸시 알림은 보내지 않습니다. 재고는 가정 전체가 공유하며, 두 사람 모두 수정할 수 있고 개인 비공개는 없습니다.

요구사항

ID 요구사항 범위
INV-01 품목을 등록·수정할 수 있다. 입력 항목은 이름, 수량, 단위, 카테고리, 보관 장소이고, 유통기한과 최소 수량은 선택이다. MVP
INV-02 품목마다 관리 방식을 고른다. 기본은 정확한 수량이고, 수량이 필요 없는 품목은 상태(충분, 부족, 없음)로 관리할 수 있다. MVP
INV-03 수량으로 관리하는 품목은 수량이 최소 수량 이하이면 “부족”, 0이면 “없음”으로 판단한다. 최소 수량을 정하지 않은 품목은 0일 때만 “없음”이다. MVP
INV-04 “다 썼어요” 버튼을 누르면 수량 품목은 0, 상태 품목은 “없음”으로 바뀐다. 이후 장바구니에 담을지 묻는 선택지를 보여 준다. MVP
INV-05 유통기한을 입력한 품목은 기한이 가까워지면 임박으로 표시된다. 임박 기준은 기본 3일 전이며 설정에서 바꿀 수 있다. MVP
INV-06 단위는 기본 목록을 제공하고, 가정 단위로 사용자가 추가·수정·삭제할 수 있다. 사용 중인 단위를 지우려 하면 해당 품목의 단위를 먼저 바꾸도록 안내한다. MVP
INV-07 카테고리는 기본 목록(식품 세분화, 생활용품, 건강·뷰티, 기타)을 제공하고, 가정 단위로 사용자가 추가·수정·삭제할 수 있다. MVP
INV-08 보관 장소는 기본 목록(냉장실, 냉동실, 실온 식품장·팬트리, 욕실·세탁실, 서랍·수납장)을 제공하고, 사용자가 추가·수정·삭제할 수 있다. “사용 안 함”으로 바꾼 장소는 화면에 노출되지 않는다. MVP
INV-09 보관 장소별, 카테고리별로 재고 목록을 조회할 수 있고 이름으로 검색할 수 있다. MVP
INV-10 품목은 직접 입력으로 등록한다. 이미 등록한 품목 이름은 입력할 때 자동완성으로 제안한다. MVP
INV-11 챗봇에 “우유 2개 샀어”처럼 직접 요청하면 확인 없이 바로 품목이 등록되거나 수량이 늘어난다. MVP
INV-12 장바구니에서 구매 완료한 품목은 확인 화면을 거쳐 재고에 반영된다. 확인 화면에서 수량과 보관 장소를 고칠 수 있다. MVP
INV-13 홈 화면에 부족, 없음, 유통기한 임박 품목을 요약해서 노출한다. 이 상태에 대해 푸시 알림은 보내지 않는다. MVP
INV-14 품목을 삭제하려면 확인 단계를 거쳐야 한다. 품목 이름이 적힌 확인 화면에서 확인을 눌러야 삭제된다. 챗봇에 직접 요청한 삭제에는 이 확인 화면을 거치지 않는다(BOT-07). MVP
INV-15 목록에서 +/- 버튼으로 수량을 바로 늘리거나 줄일 수 있다. 수량 숫자를 누르면 그 자리에서 값을 직접 입력할 수도 있다(모바일 포함). MVP
INV-16 등록할 때 비슷한 이름의 품목이 이미 있으면 알려 주고, 기존 품목에 수량을 더할지 새로 등록할지 고르게 한다. MVP
INV-17 영수증 사진을 올리면 AI가 품목을 추출하고, 기존 재고와 연결할 후보를 제안한다. 사용자가 확인 화면에서 수정한 뒤 반영한다. M3

재고 부족과 임박은 푸시로 보내지 않는 대신, AI 선제 제안이 아침 요약에 한 줄로 포함할 수 있습니다(하루 최대 1회).

SCN-BOT-5 · 직접 요청“계란이랑 두부 장바구니에 담아줘”라고 하면 확인 없이 바로 추가되고, “장바구니에 계란과 두부를 담았어요”라고 답한다. “내일 병원 일정 삭제해줘”도 확인 없이 삭제된다.
SCN-BOT-6 · 챗봇 판단 변경챗봇이 같은 시간에 겹치는 일정을 발견해 “‘치과’ 일정을 삭제해 드릴까요?”라고 물으면, 채팅 안에 확인·취소 버튼이 나온다. 확인을 누르기 전에는 아무것도 바뀌지 않고, 팝업은 뜨지 않는다.
SCN-BOT-7 · 확인 만료SCN-BOT-6의 버튼을 5분 안에 누르지 않으면 버튼이 비활성화되고 일정은 그대로 남는다.
SCN-BOT-8 · 범위 밖 질문“오늘 주식 어때?”라고 물으면 답하지 않고, 일정·재고·장바구니와 관련해 도와줄 수 있는 일을 안내한다.
SCN-BOT-9 · 기억 삭제설정의 기억 목록에서 항목 하나를 지우면 이후 대화에서 그 내용을 쓰지 않는다. 기억을 끄면 새 대화가 요약되어 쌓이지 않는다.
SCN-BOT-10 · 아이콘 최소화우하단 아이콘을 최소화하면 하단 내비게이션 바(데스크톱은 헤더)로 옮겨 가고, 화면을 이동해도 계속 보인다. 거기서 누르면 채팅창이 열린다. 앱을 다시 열어도 최소화 상태가 유지된다.

확정한 세부 정책

  • 최소화한 아이콘은 모바일에서는 하단 내비게이션 바, 데스크톱에서는 헤더에 둡니다. 우하단 아이콘은 홈 외 주요 화면에도 같은 위치로 표시합니다.
  • 기본 메시지의 기능 안내는 일정, 재고, 장바구니의 등록·수정·삭제·조회만 다룹니다. 청소 스케줄과 재정은 후순위라 MVP 안내에서 뺍니다.
  • 직접 요청이 모호할 때는 추측해서 실행하지 않고 되묻습니다. 한 번에 여러 변경을 직접 요청하면 모두 실행한 뒤 결과를 한꺼번에 알려 줍니다.
  • 챗봇이 판단한 변경이 여러 개일 때는 한 메시지에 묶어 항목별로 선택해 확인할 수 있게 합니다.
  • 기억 범위는 선호와 습관만입니다. 비밀번호·카드번호 같은 민감 정보와 배우자의 개인 일정은 기억하지 않습니다.

FEATURE · 가정·계정가정과 계정

로그인하고, 우리 집을 만들고, 배우자를 초대하고, AI 키와 알림을 설정하는 기능입니다. 온보딩은 3분 안에 끝나는 것을 목표로 합니다. MVP는 부부 두 사람이 동등한 관리자이고, 구성원과 자녀 역할은 구조만 열어 둡니다.

SCN-ACC-1 · 온보딩카카오로 로그인하고 약관에 동의한 뒤 가정 이름 “데비네”를 입력하면 가정이 만들어지고, 일정 카테고리에 “데비네”가 첫 번째로 생긴다. 초대 링크 공유 화면까지 3분 안에 도달한다.
SCN-ACC-2 · 배우자 합류배우자가 초대 링크를 열고 구글로 로그인해 수락하면 같은 가정에 합류하고, 둘 다 관리자로 표시된다. 같은 링크를 다른 사람이 다시 열면 이미 사용된 링크라는 안내가 나온다.
SCN-ACC-3 · 링크 만료3일이 지난 링크를 열면 만료되었다는 안내가 나오고, 관리자가 새 링크를 만들 수 있다.
SCN-ACC-4 · AI 키 등록관리자가 제공자를 고르고 키를 붙여 넣으면 연결 확인 결과가 나온다. 성공하면 챗봇이 자유 질문에 답하고, 화면에는 키 끝자리만 보인다. 배우자도 같은 가정의 챗봇에서 이 키를 쓴다.

SCN-ACC-7 · 홈 화면 설치스마트폰 브라우저에서 서비스를 열고 홈 화면에 추가하면 앱 아이콘으로 실행되고 주소창 없이 전체 화면으로 열린다. iOS에서는 설치 후에만 푸시 허용 안내가 나온다.

확정한 세부 정책

  • 가정 인원: 제한을 두지 않습니다.
  • 한 사용자는 한 가정에만 속합니다. 이미 다른 가정에 속한 사람이 링크를 열면 합류할 수 없다고 안내합니다.
  • 탈퇴 시 개인 일정, 챗봇 대화·기억은 삭제하고 공유 데이터는 가정에 남깁니다.
  • 마지막 관리자가 탈퇴하면, 한 명이 남아 있을 때 그 사람이 단독 관리자가 되고 모두 탈퇴하면 가정 데이터를 삭제합니다.
  • 같은 이메일로 카카오와 구글을 모두 쓰면 로그인 수단별로 별개 계정으로 취급하고, 계정 합치기는 만들지 않습니다.
  • 초대 링크는 한 번 쓰면 무효가 되고 3일 뒤 만료됩니다. 한 명을 초대할 때마다 관리자가 새 링크를 발급합니다.
