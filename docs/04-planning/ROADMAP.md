## 의존 관계 요약

```
프로젝트 초기 세팅(FSD, 린트, 포매터)
   └─ PWA 기반 ─┬─ 로그인(카카오·구글) ─ 가정 생성 ─ 초대/합류 ── (모든 기능의 전제: 가정 범위 데이터)
                └─ 일정(CAL) ── D-day ── 홈 위젯
가정 설정(카테고리·단위·보관 장소) ─ 재고(INV) ─┐
                                     장바구니(CART) ─ 구매 완료 → 재고 반영
챗봇(BOT) ← 일정·재고·장바구니 도구 + BYOK(ACC-08) + 권한 필터(CAL-04)
M3: 반복 일정 / 구글 캘린더 / OCR / 선제 제안 (+ 알림 스케줄러)
```
