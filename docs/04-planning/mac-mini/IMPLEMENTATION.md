# 앱·맥미니 구현 진행 상태

2026-11-04. 정책 승인: [ADR-0017](../../02-architecture/ADR/0017-local-family-agent.md).

## 작성한 코드

- 앱: 하단 탭 위 AI 플로팅 버튼 → `/chat` 전용 화면, 작성자·시각·맥미니 연결 상태·요청 접수/처리/완료 단계, FAQ, 전송·취소, JPEG/PNG/WebP 압축·업로드·만료 표시. 채팅에서는 하단 탭을 숨기고 입력창과 대화 스크롤을 분리한다.
- 영수증: 품목 선택·이름·수량·단위·기존 재고 연결·카테고리·보관 장소·유통기한 수정, 원자적 반영과 재시도 결과 재사용.
- 서버: 사용자 Origin 검사, 워커 Bearer 인증, 맥미니 자동 연결 설정 공급, 기억 목록·수정·삭제·초기화·끄기, 파일 정리 API.
- DB: 가정별 직렬 큐·임대·변경 기록, 비공개 채널 권한, 파일 업로드 권한, 24시간 사진 만료·5분 삭제, 7일 영수증 만료, 90일 대화 삭제, 가족 탈퇴 후 파일 삭제 예약.
- 맥미니: `ai-gateway/`, 설치된 Hermes 실행기·`kimjipsa` 전용 프로필·구조화 출력 검증, 작업 수신·재연결·임대 갱신·실패 정리, 5분 유휴 후 가족 기억 요약, 실행 후 로컬 파일 정리, Keychain 등록 도구·launchd 설정.

## 검증·실행 상태

- 타입 검사: 통과.
- 변경 파일 ESLint: 통과.
- 채팅 화면: 임시 대화 데이터로 모바일 390×844·360×640와 데스크톱 1280×900에서 진입 버튼, 입력창 고정, 대화 스크롤, 줄바꿈과 빈 입력의 전송 비활성화를 확인했다. 임시 데이터는 제거했다. 실제 AI 메시지 전송·사진 업로드는 실행하지 않았다.
- 앱 BYOK·암호화 코드와 관련 테스트는 최신 사용자 지시로 제거.
- DB 통합 테스트: 작성, 미실행. 폐기 가능한 DB가 필요하다.
- 포매팅: 수행. 최종 결과는 작업 보고 참고.
- 워커: 127.0.0.1:8644에서 `ready`. 전용 Auth 계정·가정 연결·Keychain 등록 완료. `kimjipsa` 프로필은 기존 Hermes 기본 모델·인증을 자동 사용한다. 전용 API·모델 목록·도구 비활성화를 확인했다.
- Supabase: 사용자가 SQL Editor로 두 마이그레이션을 적용했다. 워커 로그인 성공, 로컬 `/api/agent/config`가 200과 `connectionMode=local`을 반환하며 모델 키는 포함하지 않는다.
- 로컬 앱: `http://127.0.0.1:3000`에서 실행 중. 이 확인은 연결 상태 확인이며 DB 통합·실제 AI 왕복 검증을 대체하지 않는다.

## 남은 적용·인수

1. 적용한 마이그레이션의 폐기 가능한 DB 통합 검증.
2. 운영 앱 주소 설정. 로컬 Hermes 실행기·Python 환경 연결은 확인했다.
3. 텍스트·영수증 이미지의 실제 모델 왕복과 두 기기 동시 확인·취소·모델 변경·기억 삭제·네트워크 중단 검증.
4. 운영 환경의 launchd 설치와 재로그인·절전 조건 확인.
5. 승인된 가족 공용 정책과 모델 자동 연결을 기존 claude.ai 기획서·명세 원본 및 HTML 복사본에 동기화. 현재 구현은 이번 사용자 결정을 기준으로 하며 원본 문서는 수정하지 않았다.

실행 절차는 [ai-gateway README](../../../ai-gateway/README.md)에 있다. 위 인수까지 끝나기 전에는 전체 기능 완료로 표시하지 않는다.
