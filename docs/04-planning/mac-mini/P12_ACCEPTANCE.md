## 준비

- [ ] 맥북 A와 휴대폰 B는 **같은 가정의 서로 다른 계정**, 둘 다 관리자임을 설정에서 확인한다.
      관리자/일반 구성원 권한 차이는 이 구성으로 확인하지 않고 범위 제외로 기록한다.
- [ ] 운영 앱 HTTPS 주소, 배포 버전, 원격 마이그레이션 적용 확인자를 아래에 기록한다.
      이 체크리스트는 배포·원격 DB 적용·워커 신규 등록을 실행하는 지시가 아니다.
- [ ] 실제 인수에서는 두 기기의 목업을 끈다. 다른 사람의 로그인 쿠키를 복사하지 않는다.
      두 기기 모두 같은 운영 주소에 접속하는지 확인한다.
- [ ] 담당자가 테스트 전용 데이터 생성·확인·삭제에 동의한 상태에서 진행한다.
      실제 가족 일정이나 품목은 변경하지 않는다.
- [ ] A·B 각각 같은 날짜에 공유 일정 하나, 개인 일정 하나를 만든다.
      개인 일정의 제목·장소·메모는 서로 다른 임의 표식(`P12-A-T/P/M`, `P12-B-T/P/M`)으로 한다.
      테스트 전용 재고·장바구니 품목도 `P12-`로 구별하고 시작 수량을 적는다.
- [ ] 사진은 실제 개인정보가 없는 테스트 영수증 JPEG/PNG/WebP를 준비한다.
- [ ] 동시 실행은 A의 두 탭(A1/A2)을 사용한다. B가 A의 제안을 볼 수 있어야 하는 것으로 오해하지 않는다.
      B는 별도 요청을 보내 가정 내 동시 요청을 확인한다.

## 4. 맥미니 운영 (p12-4, 남은 인수 2·4)

운영 담당자가 맥미니에서 실행한다. 이 저장소 작업에서는 설정 쓰기·서비스 재시작·로그아웃·절전을 수행하지 않는다.

1. [워커 README](../../../ai-gateway/README.md#실행)의 `config.local.json`에서 `appUrl`이
   두 기기가 사용하는 운영 앱의 HTTPS origin인지 확인한다. 경로·쿼리·키를 넣지 않는다.
   로컬 전용 검사는 `http://localhost:3000`이며 운영 인수와 구분한다.
2. 변경이 필요하면 담당자가 처리 중인 요청이 끝난 뒤 로컬 설정을 수정하고,
   README의 `python3 ai-gateway/scripts/install-launchd.py`로 실행 복사본을 갱신한다.
   서비스가 잠시 중단되므로 인수 시각을 기록한다. 같은 포트에 워커를 중복 실행하지 않는다.
3. 맥미니에서 `curl -s --max-time 5 http://127.0.0.1:8644/health`로 ready/running과 HTTP 200을 확인한다.
   로그는 `~/Library/Application Support/kimjipsa/ai-gateway/.runtime/`의 워커/앱 로그를 본다.
   원문 로그 전체나 인증정보를 체크리스트에 붙이지 않는다.

## 완료 조건과 정리

- [ ] 모든 대상 행에 실환경 통과 근거가 있다. 미실행·실패가 남아 있으면 P12 완료가 아니다.
- [ ] 실패는 사용자 확인 후 수정하고 같은 두 기기·실제 모델로 재확인했다.
- [ ] 상대 개인 일정 제목·장소·메모가 응답·API·Realtime·기억 어디에도 나오지 않는다.
- [ ] 재로그인·절전 뒤 수동 시작 없이 연결이 복구되고 대화가 이어진다.
- [ ] 테스트 데이터·기억·사진은 원래 데이터를 건드리지 않고 정리했고 설정·모델을 복원했다.
- [ ] 관리자/일반 구성원 차이·P14 OCR 확장·P16 선제 제안·P22 BYOK 제외를 완료 보고에 명시했다.

## 이번 작성 세션에서 확인한 범위

- 로컬 앱 `http://localhost:3000`: HTTP 200.
- CDP 브라우저 `http://localhost:9222/json/version`: 응답 있음. 기존 탭은 `about:blank`뿐으로,
  준비된 맥북 실계정 세션은 이 브라우저에서 확인되지 않았다.
- 로컬 워커 `http://127.0.0.1:8644/health`: 접속 실패. 실제 맥미니의 중단 여부를 뜻하지 않는다.
- 목업 대화와 `docs/design/prototype/chat.html`을 375×900·1280×900으로 캡처해 시각 대조했다.
  공통 `data-od-id`인 `chat-panel`, `chat-input`, `chat-send`, `pending-confirm`,
  `pending-cancel`을 확인했다. 원본의 전용 화면·5분 만료 카드와 현재 시트/패널·수정 버튼·만료 표시 제거는
  위 최신 결정에 따른 차이로 기록한다. 이 대조만으로 실환경 시나리오 통과를 뜻하지 않는다.
  캡처는 `/private/tmp/p12-app-{375,1280}.png`, `/private/tmp/p12-reference-{375,1280}.png`에 있다.
- 목업 사용은 화면 대조에만 한정한다. 운영 주소·휴대폰·실제 모델 왕복·재로그인·절전 결과는 미확인이다.
