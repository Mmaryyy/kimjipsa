## 정리 후

- `kj-*` 클래스 정의는 80개에서 3개로 줄었다. 남은 3개는 모두 TSX에서 쓰이는 범용 유틸리티다.
- `src/shared/ui/styles.css`는 771줄에서 53줄로 줄고, 전용 스타일뿐이던 `shell.css` 194줄은 삭제했다. 셸의 공유 파생 치수는 앱 `tokens.css`로 옮겼다.
- `globals.css`에는 Tailwind·토큰 연결과 base 리셋만 둔다. 색·간격·라운드·타이포·글자 굵기 연결을 보완했다. 테마에 따라 달라지는 색은 값 대신 원래 시맨틱 변수를 참조한다.
- 기존 CSS의 상태·하위 요소·반응형·동작 줄이기 규칙도 컴포넌트의 유틸리티로 옮겼다. 가입 레이아웃과 입력처럼 반복되는 표현은 공용 CVA·Input으로 재사용한다.
- 삭제 대상 파일의 클래스 정의와 하위 선택자를 모두 이동 또는 삭제했으므로, 과거 P4.6의 사용하지 않는 하위 선택자도 별도 CSS에 남기지 않는다.

## 시각 비교 자료

현재 브라우저에 CDP로 연결하고, 목업 쿠키·동작 줄이기·375/1280px·라이트/다크로 촬영했다. 시작 전·후 자료는 `/private/tmp/kimjipsa-p4s/*.before.png`, `*.after.png`에 두고 프로토타입은 `*.prototype.png`로 보관한다. 저장소에는 스크린샷을 추가하지 않는다. 기존 전달 자료와 별도로 현재 작업 트리에서 기준을 다시 촬영했다.

동일 조건의 최종 32장을 현재 작업 트리의 기준 이미지와 픽셀 단위로 비교한 결과 모두 차이 0이었다. 프로토타입과 나란히 확인할 때 보이는 날짜·샘플 데이터·후속 Phase의 준비 중 영역은 작업 전과 동일하게 유지했다.
