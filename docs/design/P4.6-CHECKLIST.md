로컬 개발 서버 시작은 기존 개발 서버와의 중복 실행으로 종료됐다. Playwright 브라우저는 샌드박스의 Mach 포트 권한 제한으로 시작하지 못했다. 브라우저 도구의 로컬 주소 접근도 승인 검토에서 거부되어 시각 확인은 수행하지 않았다. 위 항목은 통과로 표시하지 않는다. 타입 검사와 변경 파일 ESLint·포매팅 결과는 작업 보고의 `commands_run`에 남긴다. 테스트 실행과 코드 리뷰는 수행하지 않는다.

## r042-f1 · r042-f4 세션 만료 B안

- 최초 계정 조회가 비로그인이면 기존 스플래시와 로그인 시작 화면 이동을 유지한다. 로그인 확인 뒤 계정 조회가 `200 {userId:null}`을 반환하면 401 만료로 처리하고 마지막 계정 데이터를 유지한다. 계정 캐시는 이 탭의 QueryClient가 유지되는 동안 보관한다.
- 계정 조회·다른 조회·변경 요청은 기존 토스트 한 개를 공유한다. 닫은 뒤 같은 만료에서는 다시 안내하지 않으며 창 포커스·재연결·재마운트 재조회를 억제한다. 주기 재조회도 사용하지 않는다. 새 문서나 계정 조회로 다시 확인된 로그인은 억제를 초기화한다.
- 버튼은 일반 화면에서 `/`, 초대 화면에서 `/login?invite=<token>`으로 새 문서 이동한다. 로그인·가입·약관·개인정보처리방침·개발 카탈로그에서는 안내와 이동을 하지 않는다.
- 실제 계정 훅과 게이트를 함께 사용하는 최초 비로그인·200 null 만료·화면 유지·중복 억제 테스트와 공개 화면 예외를 추가했다. 기존 홈 버튼·초대 버튼 테스트를 유지하며 테스트는 실행하지 않았다.
- 시각 확인 못 함: localhost:3000은 HTTP 200이지만 localhost:9222 연결 실패(exit 7)로 브라우저 접속 불가다. 새 브라우저는 실행하지 않았으며 375px·1280px 프로토타입 비교는 미완료다.
