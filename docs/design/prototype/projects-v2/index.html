김집사 프로젝트 통합 시안

바뀐 점 (Open Design 시안 기준, 2026-11-25)

  • 목록 행 사이에 아주 옅은 구분선(g185). 일정표만 예외.
  • 지난 마감은 회색 ‘n일 지남’ 배지 + 주황 경고 점, 늦어진 일 수·마감 강조도 주황 점 + 기본 글자색. 빨강은 쓰지 않습니다.
  • 할 일 필터는 글자 탭(44px) + 한 줄 inline 선택. 상태는 점 + 색 글자.
  • 개요 — 타임라인 행은 왼쪽 [제목 / 날짜] 두 줄, 오른쪽 막대를 두 줄 가운데에. ‘오늘 11.25’는 섹션 머리 오른쪽.
  • 결정 — 상대 의견에 👍/👎 반응, ‘고치기’·‘의견 쓰기’는 연필 아이콘 버튼.
  • 후보 — 후보마다 받을 사람 지정(확정), 묶음 없이 [사진][항목명][단가][총 금액], 모두 👍 = 선택 · 모두 👎 = 제외 · 시트에서 직접 변경, 상세 시트에 링크·메모.
  • 명단 — OD 원본 구조. 요약 면 안 태그 카드(표시만), 태그 칩 필터(누름 44px), 태그 토글, 태그 없는 칸은 비활성 토글로 줄 맞춤.
  • 예약 — 상태 배지(점 + 글자) 복귀, ‘결제 N원 … 총액 N원’ + 결제 진행 막대 + ‘남은 금액 · %’.
  • 일정표 — 세로 타임라인(왼쪽 날짜, 점, 세로선, 오른쪽 그날 카드). 빈 날은 빈 점, 여행 중 오늘은 강조. 구분선 없음(이 화면 예외).
  • 예산·지출 — 지출 행 1줄 [항목명][상태] … [결제일], 2줄 [영역 · 결제자] … [금액]. 누적 바·결제 상태 묶음·월별 목록.

가족이 몇 달짜리 큰일(결혼 준비·이사)을 영역·할 일·예산으로 나눠 관리하는 화면입니다. 화면마다 가장 중요한 숫자 하나를 맨 위에 두고, 나머지 정보는 4단계 위계로 정리했습니다.
