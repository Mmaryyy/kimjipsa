김집사 컴포넌트

앱 src/shared/ui 컴포넌트와 같은 이름·토큰으로 그린 미리보기입니다. 프로젝트 화면에서 새로 정리한 규칙(DESIGN.md §10·§11)을 함께 보여 줍니다. 왼쪽은 라이트, 오른쪽은 다크입니다.

정보 위계 4단계

한 행에 같은 단계를 두 개 두지 않습니다. 행 끝에는 상태 하나와 값 하나까지만 둡니다.

상태 배지 · D-day

StatusBadge 기본(점 + 글자) 하나만 씁니다(g204, 캡슐·칠한 알약 없음). 지난 마감은 회색 배지 + 주황 점입니다. 기본 상태(미시작·후보)는 그리지 않습니다. 마감은 D-day 배지로 따로 표시합니다.

버튼

머리 오른쪽은 유리 글자 버튼 최대 2개 [주 동작][설정]. 시트 하단 primary block은 한 화면에 하나입니다.

세그먼트 · 필터 · 검색

화면 안 전환은 SegmentedControl(26px). 필터는 글자 탭(FilterTabs, 44px, 수 붙임) + 한 줄 inline 선택(Select variant="inline")입니다. 칠한 칩은 쓰지 않습니다.

목록 행

행 사이에 아주 옅은 구분선(--separator, g185)을 긋습니다. 묶음 머리 바로 아래 첫 행 위에는 긋지 않습니다. 앞(체크·사진) · L3 · L4 · 끝(상태 + 값).

요약 면 (L1)

화면 머리 바로 아래 하나. --fill-quaternary · 4px · 16px. 축하 D-day 카드와 같은 면 규칙입니다.

진행 차트 (PRJ-15)

칸 차트는 할 일 하나 = 칸 하나. 간트는 지금 구간만 진한 막대, 오늘은 빨간 세로선입니다.

입력 · 오류 · 배너 · 토스트

오류는 라벨 색과 안쪽 테두리로만 표시합니다. 설명 문장은 붙이지 않습니다.
