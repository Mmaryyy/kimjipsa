상태 variant

개발에서 variant 값으로 쓰는 대표 상태 4가지입니다. 상태마다 같은 이름 규칙의 토큰이 있고, 컴포넌트에 data-variant="success | info | warning | error"만 주면 점·글자·배경·버튼 색이 함께 바뀝니다.

컬러 코드

구현할 때 그대로 옮겨 쓰는 원본 값입니다. 이름에 모드가 붙은 토큰(--success-light, --success-dark …)은 모드와 상관없이 고정이고, 화면에서는 모드에 따라 바뀌는 --success 같은 시맨틱 토큰을 씁니다.

김집사 상태 매핑

화면의 도메인 상태는 위 4가지 variant의 별칭입니다. 없음은 error, 부족은 warning, 반영됨은 success, 정보는 info를 따르고, 유통기한 임박·개인 일정만 김집사 전용 색입니다.

상태 Apple 컬러 토큰 쓰는 곳
없음 Red --status-none → error 재고 0 · 상태 "없음", 삭제·탈퇴 같은 파괴적 행동
부족 Orange --status-low → warning 최소 수량 이하, 연결 끊김 안내
3일 남음 Yellow --status-expiring 유통기한 임박 (기본 3일 전)
반영됨 Green --status-ok → success 충분, 구매 반영 완료, 키 연결됨, 스위치 켬
기존 재고에 더함 Blue --status-info → info 주 액션 버튼, 링크, 선택, 정보
개인 일정 Gray --status-private 배우자의 개인 일정 (시간만, 희미하게)
김데비 Indigo --bot 집사 아이콘, 집사 이름 표기만
D-5 Pink --celebrate 축하 D-day (D-7부터 강조, 당일 축하 배너)

타이포그래피
