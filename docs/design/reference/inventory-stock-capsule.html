재고

상태로 관리하는 품목의 오른쪽 값을 눌러 보세요.

이해한 내용

  1. 버튼 묶음(충분 · 부족 · 없음)은 지금 것을 그대로 쓰고, 재고 상태 버튼만 모서리를 완전한 캡슐로 키워요. 위쪽 보기 전환 등 다른 버튼 묶음은 그대로예요.
  2. 수량 품목도 같은 효과예요. 평소엔 1팩 캡슐, 누르면 좌우로 늘어나 − 1팩 +가 돼요. 여러 번 누를 수 있게 바로 접지 않고 바깥·Esc로 접혀요.
  3. 보이는 캡슐 높이는 지금 앱과 같은 30px이고, 누르는 영역만 44px이에요.
  4. 평소에는 지금 값 하나만 색 캡슐로 보여요. 충분 초록, 부족 주황, 없음 빨강이에요.
  5. 값을 누르면 캡슐이 좌우로 늘어나며 세 칸 버튼 묶음이 되고, 하나를 고르면 잠깐 뒤 다시 그 값 하나로 접혀요.
  6. 바깥을 누르거나 Esc를 누르면 그대로 접혀요. 한 번에 한 줄만 펼쳐져요(수량 스테퍼와 같은 규칙).
