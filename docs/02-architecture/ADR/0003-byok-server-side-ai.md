# 0003. AI: BYOK + 서버 라우트 호출 + 요청자 권한 필터

- 결정 ID: ADR-0003
- 결정 날짜: 2026-10-14 (`AGENTS.md` 반영일. 실제 결정일은 확인 필요)
- 상태: Accepted

## 배경
무료 서비스라 AI 비용을 서비스가 부담할 수 없다. 챗봇은 개인 일정을 포함한 가정 데이터를 조회하므로 배우자에게 비공개 내용이 새면 안 된다(CAL-04, BOT-10).

## 검토한 대안
기획서와 `AGENTS.md`에는 대안(서비스 부담 키, 사용자별 키) 검토 기록이 남아 있지 않다.

## 최종 결정
- BYOK: 관리자가 Claude 또는 Gemini 키를 하나 등록하고 가정 전체가 공유한다. 키는 서버에서 암호화해 저장한다.
- AI와 외부 API 호출은 모두 서버 라우트를 거치고, 제공자 차이는 어댑터 한 겹으로 감싼다.
- 데이터는 항상 요청자 권한으로 걸러서 내려보내며, 챗봇 도구 호출도 질문자 권한으로 같은 필터를 거친다.
- 사용자가 직접 요청한 변경은 바로 실행하고, 챗봇이 스스로 판단한 변경만 채팅 안의 확인 버튼을 거친다.

## 결정 이유
키가 브라우저에 노출되지 않고, 권한 규칙이 화면과 챗봇에서 갈라지지 않는다.

## 예상 영향
- 키 암호화 방식과 키 관리(교체·유출 대응)를 따로 정해야 한다 → DEC-003.
- 제공자마다 도구 호출·OCR 품질이 달라 출시 전 핵심 시나리오를 제공자별로 점검한다(기획서 §11, §12).
- 키가 없으면 AI 기능만 꺼지고 기본 메시지·FAQ는 동작해야 한다(BOT-05).
