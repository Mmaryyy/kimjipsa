# 0025. 차트 라이브러리(shadcn/ui Chart, recharts)

- 결정 ID: ADR-0025 (관련 결정: g196, g198)
- 결정 날짜: 2026-11-25
- 상태: CONFIRMED (2026-11-25 사용자 지시: 차트 라이브러리를 도입하고 기존 차트도 가능하면 대체)

## 배경

프로젝트 예산 화면(PRJ-10) 최상단 요약을 별도 카드에 대시보드처럼 차트와 함께 보여 주기로 했다(g196). 지금 앱에는 차트 라이브러리가 없고, 프로젝트 진행률 반원 게이지(`entities/project/ui/project-progress-gauge.tsx`)를 SVG로 직접 그린다. 차트가 늘어날수록 직접 그린 SVG는 축·툴팁·접근성·반응형을 매번 다시 만들어야 한다.

## 결정

- 차트는 shadcn/ui Chart 구성(`ChartContainer`·`ChartTooltip` 등)과 그 기반인 `recharts`로 그린다. shadcn/ui 는 ADR-0004 에서 확정한 UI 프리미티브이고, Chart 구성은 recharts 위에 테마 변수를 연결하는 얇은 래퍼다.
- 공용 래퍼는 `src/shared/ui` 한 곳에 두고 화면은 래퍼만 쓴다. 색은 `tokens.css` 토큰만 쓴다(g003).
- 앱의 기존 차트(프로젝트 진행률 반원 게이지 등)도 가능하면 같은 라이브러리로 바꾸고 모양은 최대한 유지한다.
- 정확한 버전은 `package.json`·`yarn.lock` 과 `TECH_STACK.md` 에 기록한다.

## 검토한 대안

- 직접 그린 SVG 유지: 의존성은 없지만 차트 종류가 늘 때마다 축·툴팁·반응형을 새로 만들어야 한다.
- 다른 차트 라이브러리(Chart.js, visx 등): shadcn/ui Chart 와 바로 연결되지 않아 테마·래퍼를 따로 만들어야 한다.

## 결과

- 의존성이 하나 늘고 번들이 커진다. 차트가 있는 화면에서만 불러오도록 한다.
- 차트 색·글꼴은 디자인 토큰을 따라 다크 모드에서도 같은 규칙으로 바뀐다.
