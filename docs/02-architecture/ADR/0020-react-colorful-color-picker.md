# 0020. 카테고리 직접 색 선택

Status: CONFIRMED (2026-11-09 사용자 승인)

## 맥락

네이티브 컬러 창은 앱 디자인과 맞지 않고, 카테고리 색 선택에 필요 없는 RGB 입력을 보여 준다.

## 결정

- `react-colorful` 5.8.1을 정확한 버전으로 고정하고 `HexColorPicker`를 사용한다.
- 모바일(md 미만)은 카테고리 편집 시트 위 중첩 Sheet, 데스크톱은 기존 `radix-ui`의 Popover로 스포이드 버튼 아래에 연다.
- 제목은 '색 직접 선택'이며 채도·밝기 사각형과 색상 막대만 표시한다. RGB·hex 입력은 두지 않는다.
- 머리에 취소·선택을 두고 선택할 때만 소문자 `#rrggbb`를 폼에 반영한다. 취소·ESC·바깥 클릭은 기존 값을 유지하고 스포이드 버튼으로 포커스를 돌린다.
- 처음 열 때 이전 직접 색, 현재 선택된 색의 hex, 첫 프리셋 순으로 시작 색을 고른다.
- 컴포넌트 안에서 모서리·그림자 토큰과 흰 핸들 테두리, 44px 이상 터치 영역을 적용한다. 라이트·다크에서 같은 피커를 쓴다.

## 대안

- 네이티브 창 유지: 의존성은 없지만 디자인 불일치와 불필요한 입력을 해결하지 못한다.
- 직접 구현: 의존성은 없지만 색 변환·포인터·키보드 접근성 구현과 유지 비용이 크다.

## 결과

앱 안에서 색을 미리 보고 확정할 수 있다. 의존성은 `react-colorful` 하나만 추가하고 기존 Sheet·버튼·미디어 쿼리 훅·색 유틸을 재사용한다. 피커 도입 자체는 DB·RPC·권한을 바꾸지 않는다. 저장 색 기록은 [데이터 모델](../DATA_MODEL.md)의 저장 색 테이블 정책을 따른다.
