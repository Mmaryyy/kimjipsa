# 0001. 플랫폼 스택: PWA + Next.js + Supabase + Vercel

- 결정 ID: ADR-0001
- 결정 날짜: 2026-10-14 (`AGENTS.md` 반영일. 실제 결정일은 확인 필요)
- 상태: Accepted

## 배경
혼자 8주 안에 일정·재고·장바구니·챗봇을 만들어야 한다. 부부가 스마트폰에서 홈 화면 앱처럼 쓰고, 장바구니는 실시간 공동 편집이 필요하다(CART-02). 인증은 카카오·구글이다(ACC-01).

## 검토한 대안
기획서와 `AGENTS.md`에는 대안 검토 기록이 남아 있지 않다. (네이티브 앱, 자체 백엔드 등은 검토 여부 확인 필요.)

## 최종 결정
모바일 우선 PWA를 Next.js로 만들고, 백엔드는 Supabase(Auth, Postgres+RLS, Realtime), 배포는 Vercel로 한다.

## 결정 이유
- 앱스토어 심사 없이 홈 화면 설치와 웹 푸시를 제공(ACC-17).
- Supabase Realtime으로 공동 편집, Auth로 카카오·구글 로그인, RLS로 가정 단위 격리.
- 서버 라우트에서 권한 필터링과 AI 호출을 같은 코드베이스로 처리.

## 예상 영향
- iOS 웹 푸시는 홈 화면에 추가한 PWA에서만 동작한다. 온보딩에서 설치를 안내해야 한다(ACC-11).
- 예약 작업(아침 요약 등)은 Supabase/Vercel 안에서 별도 해결이 필요하다 → DEC-004.
- 구글 로그인·캘린더 승인을 위해 자체 도메인이 필요하다(기획서 §11).
