# 0015. 달력 스와이프: embla-carousel-react

- 결정 ID: ADR-0015 (관련: CAL-07)
- 결정 날짜: 2026-10-20
- 상태: Accepted

## 배경
사용자가 일정 화면 달력을 손가락으로 밀어 이전·다음 달(주·일)로 넘기길 원했다(2026-10-20). 달력이 손가락을 따라 끌리다 놓으면 넘어가는 동작을 골랐다.

## 검토한 대안
- 직접 구현(포인터 이벤트 + transform): 의존성은 없지만 관성·되돌림·세로 스크롤 구분을 직접 맞춰야 한다.
- 캘린더 전체 라이브러리(FullCalendar, react-big-calendar 등): 지금 만든 월·주·일 보기, 개인 일정 가림(CAL-04), 공휴일 표시를 다시 만들어야 해서 쓰지 않는다.

## 최종 결정
- 스와이프만 `embla-carousel-react` 8.6.0으로 처리한다. 달력 그리기와 날짜 계산은 지금 코드(date-fns)를 그대로 쓴다.
- 이전·현재·다음 세 장을 `loop: true`로 유지한다. `select` 즉시 제목·날짜·URL 상태(`date`)를 갱신하고, `settle` 뒤 가운데 장으로 복귀한다. 빠른 연속 넘김은 현재 선택 장을 기준으로 계산한다.
- URL 갱신은 `history.replaceState`를 사용해 이전·다음 이동마다 방문 기록이 쌓이지 않게 한다. 오늘 버튼이나 보기 전환 등 외부 날짜·보기 변경은 가운데 장으로 즉시 재설정한다.
- 이전·다음 버튼은 그대로 둔다(스와이프만으로 이동하지 않는다). 세로 스크롤은 방해하지 않고, 동작 줄이기 설정에서는 `duration: 0`을 적용하고 `pointerUp`에서 선택 장으로 즉시 이동(`scrollTo(index, true)`)한다.

## 예상 영향
- 의존성 1개(작은 크기). 일정 화면(`widgets/calendar-view`)에만 쓴다.
