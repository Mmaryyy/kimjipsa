# 화면 영역 결정: calendar

- g010: 날짜 라이브러리는 date-fns 를 유지하고 @date-fns/tz 도 쓴다(KST 고정). dayjs 로 바꾸지 않는다. ADR-0004 에 한 줄 기록. (원래 kimjipsa-build d011)
- g013: 공유 일정을 개인으로 전환하는 것은 작성자만 할 수 있다(비작성자는 전환 불가, 서버·DB에서 거부) (원래 kimjipsa-build d016)
- g014: 일정의 날짜는 필수, 시작·종료 시각은 각각 선택. 둘 다 비면 시간 미정이며 종일과 별개로 그날 칸 맨 아래에 시각 없이 표시. 저장은 start_date/end_date + 선택 start_time/end_time (원래 kimjipsa-build d017)
- g015: 일정 카테고리 표시 순서는 사용자가 바꿀 수 있고(sort_order), 기본은 가정 이름 카테고리가 맨 앞·나머지 이름순 (원래 kimjipsa-build d018)
- g016: 일정 화면에서도 카테고리 관리로 들어가는 링크를 유지한다(일정에 필요한 기능은 그 화면에서도 진입 가능, 다른 페이지도 동일) (원래 kimjipsa-build d019)
- g019: 목업 데이터에 시간 미정 일정 샘플은 넣지 않는다 (원래 kimjipsa-build d024)
- g023: 주의 시작 요일은 모든 화면(홈 주간 스트립 포함)에서 일요일이다 (원래 kimjipsa-build d028)
- g030: 일정 카테고리 순서는 목록에서 드래그 앤 드롭으로 바꾼다. 드래그 라이브러리는 dnd-kit(@dnd-kit/core·sortable·utilities, 터치·키보드 지원). 저장은 기존 save_event_category(sortOrder)로 한 카테고리만 보내고 마이그레이션은 없다. 편집창의 '표시 순서' 숫자 칸은 없앤다. 새 의존성은 TECH_STACK.md 에 기록(P4.9) (원래 kimjipsa-build d036)
- g032: 달 밖 날짜는 일요일이어도 회색(--label-tertiary) 유지 (사용자 결정 2026-10-20) (원래 kimjipsa-build d038)
- g033: 공휴일 캐시(B안): 검증 통과한 목록만 연도 키로 서버 데이터 캐시, 3시간 재검증, 실패 시 이전 값 유지, DB 테이블 없음 (사용자 결정 2026-10-20, r064-f1) (원래 kimjipsa-build d039)
- g036: 일 보기와 월 선택일 목록의 줄 순서를 같게 한다: 공휴일 → 절기·잡절 → 빈 상태 문구/일정 (사용자 결정 2026-10-21) (원래 kimjipsa-build d045)
- g038: 종일·시간 미정 일정의 알림 시점은 그날 00:00 기준 n분 전으로 계산한다(같은 선택지 사용) (사용자 결정 2026-10-21) (원래 kimjipsa-build d050)
- g039: 배우자 변경 알림(CAL-09)에 공유 일정 삭제도 포함한다(프로토타입 삭제 확인 문구 기준). 명세 원본 문구는 사용자 요청 시 수정 (사용자 결정 2026-10-21) (원래 kimjipsa-build d051)
- g040: 시간 미정은 일정 폼의 '시간 미정' 스위치로 만든다(데스크톱 포함, 종일 아래) (사용자 결정 2026-10-21) (원래 kimjipsa-build d054)
- g041: 알림 기본값은 모든 일정 30분 전. 종일·시간 미정은 00:00 기준이라 전날 23:30에 간다 (사용자 결정 2026-10-21) (원래 kimjipsa-build d055)
- g043: 일정 삭제 확인창은 공유·개인과 구성원 수에 관계없이 '삭제한 일정은 되돌릴 수 없어요'만 보여 준다(배우자 삭제 알림 안내 문구 없음). 알림 목록은 최근 30개만 보여 준다 (사용자 결정 2026-10-21, r093-f7·f11) (원래 kimjipsa-build d060)
- g045: 모바일 일정 추가·수정 시트는 vaul 1.1.2 Drawer(손잡이, 아래로 끌어 닫기)로, 데스크톱은 가운데 시트 유지. vaul 은 유지보수 중단 상태임을 알고 승인, shared/ui 래퍼 한 곳에 둔다. P5.5에 포함 (사용자 결정 2026-10-21) (원래 kimjipsa-build d069)
- g049: 시작 전 알림(푸시·앱 내 목록)에 일정 제목과 시작 시각을 보여 준다. 수신자는 그 일정을 볼 수 있는 사람뿐(개인 일정은 본인만)이라 개인 일정 규칙과 충돌하지 않는다 (사용자 결정 2026-10-22) (원래 kimjipsa-build d074)
- g058: 달력 여러 날 일정은 P5.6 에서 월 달력 날짜 칸에 가는 막대(색점 높이, 일정 분류 색 + 투명도, 제목 없음)로 표시한다. 일정 목록 행에는 기간 텍스트를 넣지 않는다 (사용자 결정 2026-10-22) (원래 kimjipsa-build d090)
- g062: 월 달력 날짜 칸 세로 간격은 '눈으로 보이는' 간격 기준으로 같게 한다: 날짜 배지·이름·색점·막대의 박스를 보이는 크기에 맞추고 그 사이를 같은 간격으로. 스크린샷 픽셀 측정으로 확인 (사용자 지시 2026-10-22, r136-f1) (원래 kimjipsa-build d097)
- g072: 반복 일정: 규칙 + 회차 예외 행, '이후 모든 일정'은 규칙을 끊고 새 일정으로 분할 (DEC-009, 2026-10-30) (원래 kimjipsa-build d114)
- g084: 하위 화면(가정·초대·약관·일정 카테고리·준비 중)은 데스크톱 520px narrow 로 확정(§2-1). 투명도 줄이기에서는 누르는 동안 원래 선택 탭을 파랑 그대로 둔다 (사용자 2026-11-02) (원래 kimjipsa-build d144)
- g095: 설정 하위 화면(재고 목록·일정 카테고리) 뒤로 버튼은 라벨 없이 셰브론 아이콘만, aria-label '뒤로'. 앱 안 진입은 히스토리 뒤로, 직접 진입은 출처(from) 화면 없으면 설정 (사용자 2026-11-05) (원래 kimjipsa-build d168)
- g103: 카테고리 색점에는 테두리를 두지 않는다(사용자 2026-11-09) (원래 kimjipsa-build d185)
- g104: 카테고리 색 선택: 한 번이라도 저장한 직접 색은 가정 단위로 남겨 칩으로 재선택, 프리셋+저장 색+직접 선택은 최대 2줄 (사용자 2026-11-09) (원래 kimjipsa-build d186)
- g105: 카테고리 색 칩 목록에서 프리셋 6색은 항상 보인다. 2줄을 넘으면 저장한 색 칩만 오래된 것부터 숨긴다 (사용자 2026-11-09) (원래 kimjipsa-build d187)
- g106: 카테고리 색 '직접 선택'은 스포이드(Pipette) 아이콘의 리퀴드 글래스 원형 버튼으로, 칩 줄 마지막 칸 (사용자 2026-11-09) (원래 kimjipsa-build d188)
- g108: P11.4 스켈레톤: 달력·주간 날짜는 진짜 날짜를 바로 표시, 데이터 목록은 섹션 단위 큰 카드 블록, 고정 요소는 진짜로 (사용자 2026-11-10) (원래 kimjipsa-build d200)
- g119: 일정 폼·아침 요약 시각·재고 유통기한 등 앱의 모든 날짜·시간 입력은 공용 컴포넌트로 통일한다. P5.5에서 도입한 iOS식 휠 선택기(@ncdai/react-wheel-picker 1.2.3)를 사용한다. 모바일(pointer: coarse)은 휠 시트로 고르고, 데스크톱은 값을 표시한 뒤 가운데 중첩 시트에서 휠로 고른다. 데스크톱에서 시트를 열면 시트 자체에 포커스한다. (통합: d053·d078·d216, 사용자 지시·결정 2026-10-21·2026-10-22·2026-11-12, P5.5·r117-f1) (원래 kimjipsa-build d226)
- g121: 홈 오늘 일정에는 오늘에 걸친 일정과 오늘 D-Day를 표시한다. D-Day 섹션(DdayOverview)은 ddayOccurrences로 오늘을 포함한 다음 D-Day를 가까운 순서대로 보여 준다. 다가오는 일정(UpcomingEvents)은 upcomingOccurrences로 내일부터 표시하고, 여러 날 일정은 내일 이후 남은 첫날에 한 번만 표시한다. 두 계산은 nextDday·compareOccurrences만 공유한다. (통합: d068·d070, 사용자 결정·요청 2026-10-21, CAL-13·r110-f1) (원래 kimjipsa-build d228)
- g122: 배우자 변경 푸시 본문은 잠금 화면에서도 ‘제목’ 일정이 등록되었어요 / 변경되었어요 / 삭제되었어요. 형식으로 일정 제목을 표시한다. 공개 범위 전환은 ‘제목’ 일정의 참가 인원이 변경되었어요.로 보낸다. 공유→개인은 전환 전 공유 제목만 쓰고 새 개인 제목은 보내지 않는다. 개인→공유는 현재 제목을 쓴다. ADR-0013의 본문 규칙에 반영한다. (통합: d077·d080, 사용자 결정 2026-10-22, r116-f2·r117-f2) (원래 kimjipsa-build d229)
- g123: 일정 목록 행의 보조 정보는 공개 범위(공유|개인 일정) → 소유자(개인 일정만, 내 것은 ‘나’, 배우자 것은 작성자 이름) → 장소 → ‘HH:mm까지’ 순서로 표시한다. 내 개인 일정은 자물쇠를 숨기고 배우자 개인 일정은 자물쇠를 표시한다. 여러 날 일정의 기간 텍스트는 목록 행에 넣지 않는다. 짧은 라벨은 ‘공유’(개인 일정은 작성자 이름)를 쓴다. 상세에서는 ‘공유 일정’·‘개인 일정’, 폼에서는 ‘기본은 가족 모두가 함께 보는 공유 일정이에요.’를 쓴다. 기능명세·프로토타입에 남은 ‘둘 다’ 문구는 사용자 승인 후 고친다. (통합: d083·d087·d089, 사용자 위임·지시·결정 2026-10-22, r118-f1·r121-f1·r124-f1) (원래 kimjipsa-build d230)
- g124: 여러 날 일정 막대는 h-2(8px), opacity-50, 시작·끝 모서리 var(--r-bar)(2px)를 사용한다. 첫 막대 줄은 색점 바로 아래에 둔다. (통합: d098·d099, 사용자 지시 2026-10-22, r139) (원래 kimjipsa-build d232)
- g130: 카테고리 직접 색은 react-colorful 5.8.1 피커로 고른다. 모바일은 중첩 시트, 데스크톱은 팝오버로 열고 채도 사각형과 색상 막대만 보여 준다. 선택 색 미리보기 원과 RGB·hex 입력은 두지 않으며 [선택]으로 확정한다. (통합: d189·d191, 사용자 결정 2026-11-09, ADR-0020) (원래 kimjipsa-build d238)
- g131: 카테고리 색 칩은 모바일에서 7열×2줄 격자로, 데스크톱에서 36px 칸과 8px 간격의 flex-wrap으로 배치한다. 양쪽 모두 프리셋 6개, 저장 색 최대 7개, 스포이드 1개로 총 14개까지 표시한다. (통합: d190·d192, 사용자 결정 2026-11-09) (원래 kimjipsa-build d239)
- g132: 일정 화면 머리는 두 줄로 구성한다. 첫 줄 왼쪽은 기간 제목(title-lg), 오른쪽은 [등록] [설정]이다. 둘째 줄 왼쪽은 [월 | 주 | 일] 전환, 오른쪽은 [이전] [오늘] [다음]이다. 주 보기 제목은 ‘yyyy년 M월 N주차’로 표시하고, 주의 목요일이 속한 연월과 그 목요일의 날짜를 7로 나눠 올림한 주차를 쓴다. (통합: d041·d123·d127, 2026-10-20·2026-10-30·2026-11-02, r068-f5·f6·r071) (원래 kimjipsa-build d241)
- g133: 일정·재고 화면 머리 오른쪽에는 [등록] [설정]을, 장바구니에는 편집 모드 폐지에 따라 [설정]만 둔다. [설정]은 해당 관리 화면을 열며 장바구니 카테고리 순서 변경은 재고 카테고리 관리 화면에서 함께 제공한다. 화면 아래쪽의 [카테고리 관리하기]는 제거한다. 다른 곳에 남아 있는 ‘OO 관리하기’ 같은 보조 이동 동작은 전체 너비의 회색 보조 버튼으로 제공한다. 등록 문구 변경은 화면·테스트·DESIGN_SYSTEM에 반영하고, 프로토타입·기획서·명세의 동일 문구는 사용자 요청 시 갱신한다. (통합: d120·d122·d123·d124·d127·d137, 2026-10-30·2026-11-02) (원래 kimjipsa-build d242)
- g155: 탈퇴한 사용자의 공유 일정은 보존하고 작성자 참조를 비워 ‘탈퇴한 사용자’로 표시한다. 개인 일정은 ACC-15에 따라 삭제한다. (원래 kimjipsa-build d021의 규칙 부분)
- g157: 캘린더 화면은 전용 UI 라이브러리 없이 직접 구현한다. (원래 kimjipsa-build d040의 규칙 부분)
- g158: 절기·잡절은 항상 회색 이름으로 표시하고 날짜 숫자 색은 유지한다. 공휴일과 겹치면 날짜 칸에는 공휴일을 우선하고 목록에는 둘 다 표시한다. 위젯과 일정 개수에서는 제외한다. (원래 kimjipsa-build d044의 규칙 부분)
- g159: 절기 데이터는 get24DivisionsInfo에서 가져오고 목업은 실제 API 응답 형식에 맞춘다. (원래 kimjipsa-build d046의 규칙 부분)
- g164: 카테고리 색은 정해진 프리셋 6색과 #rrggbb 직접 선택을 지원하며 빨강도 허용한다. 흰색·검은색 글자 자동 선택은 공용 함수로 제공한다. (원래 kimjipsa-build d184의 규칙 부분)
- g169: 재고 행을 왼쪽으로 밀면 수정·다 씀·삭제, 일정 행을 밀면 수정·삭제를 제공한다. 장바구니와 같은 모양과 동작의 shared 공용 컴포넌트를 쓴다. (원래 kimjipsa-build d215의 규칙 부분)
