- g042: 설정 섹션 순서(사용자가 Claude에게 위임, 사용자 편의성 기준): 내 정보 → 알림 → 홈 화면 → 화면 → 구성원 → 가정 → AI 집사 → 기억 → 계정. 개인 설정을 위, 가정 공용 설정을 아래, 계정 동작을 맨 아래. 홈 화면 섹션 안의 행 순서는 다가오는 일정 → 캘린더 보기 → 표시 개수(사용자가 직접 변경). 프로토타입 settings.html 과 다르며 DESIGN.md·HANDOFF.md 에 기록한다 (2026-10-21) (원래 kimjipsa-build d058)
- g050: 웹 푸시 on/off 는 계정 단위다(users.push_enabled). 한 기기에서 끄면 모든 기기에 안 가고, 켜면 구독된 모든 기기에 간다. 설정 스위치는 계정 값을 보여 준다 (사용자 결정 2026-10-22) (원래 kimjipsa-build d075)
- g056: 구성원 역할은 텍스트 대신 작은 lucide 아이콘으로 표시한다: 관리자 BicepsFlexed, 구성원 없음, 자녀 Baby. 크기는 옆 텍스트 글자 크기 이하, 스크린리더 이름은 역할명 (사용자 지시 2026-10-22, r120-f1) (원래 kimjipsa-build d086)
- g070: 탈퇴 시 초대: 탈퇴자가 만든 안 쓴 초대 링크는 삭제하고, 이미 쓴 초대 기록은 created_by·accepted_by만 null로 비워 남긴다(DEC-009 ⑤, 사용자 결정 2026-10-28). invitations.created_by는 nullable로 바꾼다 (원래 kimjipsa-build d108)
- g071: 탈퇴자가 만든 공유 항목(장바구니 added_by·checked_by 등 사용자 참조 FK)은 null로 비우고 '탈퇴한 사용자'로 표시한다(DEC-009 ④를 공유 항목 전체에 적용) (원래 kimjipsa-build d110)
- g084: 하위 화면(가정·초대·약관·일정 카테고리·준비 중)은 데스크톱 520px narrow 로 확정(§2-1). 투명도 줄이기에서는 누르는 동안 원래 선택 탭을 파랑 그대로 둔다 (사용자 2026-11-02) (원래 kimjipsa-build d144)
- g097: CART-05 자주 사는 품목 편집: 목록은 구매 기록 자동 계산 유지, 품목별로 카테고리·단위·메모·링크 값만 덮어써 저장(수량은 1 고정, 수정 불가). 편집 화면은 설정 하위 화면. 숨기기 여부는 미정 (사용자 2026-11-05) (원래 kimjipsa-build d174)

- g099: 자주 사는 품목 덮어쓰기: 숨김 토글은 hidden만 저장, 저장값의 카테고리·단위가 null이면 원래 값으로 폴백 (원래 kimjipsa-build d179)
- g100: 자주 사는 품목 설정 목록은 '장바구니에 보이는 품목'과 '그 밖의 후보' 두 묶음으로 나눈다 (원래 kimjipsa-build d180)

- g112: 약관 재동의 화면은 한 줄 버튼 규칙의 예외: 안내 → [로그아웃] → [탈퇴하기] → [동의하고 계속] 세로 순서로 둔다 (사용자 2026-11-12) (원래 kimjipsa-build d214)
- g125: 관리자는 설정의 구성원 목록에서 일반 구성원·자녀의 역할을 바꾸거나 관리자로 올릴 수 있다. 다른 관리자의 역할은 바꿀 수 없고, 관리자는 다른 관리자가 남아 있을 때만 스스로 강등할 수 있다. 역할 변경 RPC에도 같은 규칙을 적용한다. 다른 구성원이 남는 상태에서 마지막 관리자가 탈퇴하려면 먼저 다른 구성원에게 관리자 권한을 넘겨야 한다. 자동 승계는 하지 않으며 모두 탈퇴하면 가정 데이터를 삭제한다. (통합: d109·d111, 사용자 결정 2026-10-28) (원래 kimjipsa-build d233)
