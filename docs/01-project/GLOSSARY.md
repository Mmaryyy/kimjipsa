# 용어집

코드 식별자는 영어, 화면 문구는 한국어를 쓴다. 한 개념은 한 용어로 통일한다. (`CODING_STANDARDS.md` §3)

| 용어 | 코드 식별자 | 뜻 |
| --- | --- | --- |
| 가정 | `family` | 사용자가 속하는 단위. 한 사용자는 한 가정에만 속한다. 인원 제한 없음 |
| 관리자 | `admin` | MVP에서 가정에 합류한 모든 사람. 역할은 `admin`, `member`, `child`이고 MVP 화면은 `admin`만 쓴다 |
| 공유 일정 | `visibility: shared` | 기본값. "둘 다" 참석자. 가정 구성원 모두 보고 수정한다 |
| 개인 일정 | `visibility: private` | 작성자만 내용을 보고 수정한다. 배우자에게는 시간 칸만 희미하게 보인다 |
| D-day | `kind: dday` | 기념일을 통합한 일정 종류. 매년 같은 날짜로 반복하고 "D-363" 형식으로 남은 일수를 표시한다 |
| 축하 D-day | `dday_style: celebrate` | 당일 홈 맨 위에 축하 카드와 N주년을 보여 주는 D-day. 반대는 `normal` |
| 재고 품목 | `inventory_item` | 집에 있는 물건. 관리 방식(`mode`)이 `quantity` 또는 `status` |
| 상태 모드 | `mode: status` | 수량 대신 `enough` / `low` / `none`으로 관리하는 품목 |
| 최소 수량 | `min_quantity` | 수량 품목의 "부족" 기준. 이하이면 부족, 0이면 없음 |
| 임박 | - | 유통기한이 가까운 상태. 기본 3일 전, 가정 설정에서 변경 |
| 다 썼어요 | - | 수량 품목은 0, 상태 품목은 "없음"으로 바꾸고 장바구니 담기를 묻는 버튼 |
| 보관 장소 | `location` | 냉장실 등. "사용 안 함"이면 선택지·조회에서 숨기되 품목은 유지 |
| 단위 | `unit` | 개, 팩 등 가정 단위 목록 |
| 구매 완료 | - | 체크한 장바구니 항목을 재고 반영 확인 화면으로 넘기는 동작. 처리된 항목은 구매 기록(`purchased_at`)으로 남는다 |
| 집사 / 챗봇 | `chat` / `bot` | AI 챗봇. 이름은 가정에 하나이며 "김" + 이름으로 표시 |
| 직접 요청 | - | 사용자가 챗봇에게 말한 변경. 확인 없이 바로 실행(BOT-07) |
| 챗봇 판단 변경 | `pending_action` | 챗봇이 맥락으로 판단해 제안한 변경. 채팅 안 확인 버튼을 눌러야 실행, 5분 뒤 만료(BOT-08) |
| 기본 메시지 | - | 채팅창을 열면 AI 없이 보내는 안내·FAQ·키 등록 방법(BOT-03) |
| 요약 기억 | `memory` | 대화 종료(5분 무활동) 후 요약해 사람별로 쌓는 선호·습관 |
| BYOK | - | Bring Your Own Key. 관리자가 등록한 AI 키를 가정이 공유 |
| 제공자 | `provider` | AI 제공자. MVP는 `claude`, `gemini` |
| 아침 요약 | - | 매일 지정 시각(기본 10시)에 당일 일정을 한 건으로 묶은 푸시 |
| 선제 제안 | - | AI가 먼저 건네는 제안. 하루 최대 1회, 아침 요약에 포함(M3) |
| 도그푸딩 | - | 제작자 부부가 직접 써 보는 1차 사용 |
| FSD | - | Feature-Sliced Design. 레이어는 `app`, `pages`, `widgets`, `features`, `entities`, `shared` |
| 슬라이스 / 세그먼트 | - | 레이어 아래 한 단계 폴더 / 슬라이스 안의 `ui`, `model`, `api`, `lib`, `config` |
| 요구사항 ID | `CAL-03` 등 | 접두사 `CAL`, `INV`, `CART`, `BOT`, `ACC` + 번호 |
| 확인 시나리오 | `SCN-CAL-1` 등 | 요구사항 검증용 시나리오. 형식 `SCN-<영역>-<번호>` |
| 범위 | `MVP`, `M3`, `v1.1` | 요구사항이 들어가는 시점. 마일스톤 의미는 ROADMAP 참고 |
