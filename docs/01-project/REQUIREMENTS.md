# 요구사항

`docs/기능명세.html`(v0.11)의 요구사항을 개발에 쓰기 쉽게 정리한 색인이다. **원본을 대체하지 않는다.** 문구가 다르다고 느껴지면 원본이 맞다. 요구사항 ID와 시나리오 ID(`SCN-<영역>-<번호>`)는 원본 그대로 쓴다.

- 확정 여부: 표의 모든 요구사항은 명세 v0.11 기준 **CONFIRMED**다. 명세의 "데이터 항목"은 원본에서 "(제안)"이라 `DATA_MODEL.md`에서 **PROPOSED**로 다룬다.
- `[확인 필요]`는 원본에서 확인할 수 없거나 모호한 부분이고, 해당 결정 번호(`DEC-xxx`)는 `docs/04-planning/DECISIONS_REQUIRED.md`에 있다. 이 문서에서 임의로 해석하지 않는다.
- 범위: `MVP` / `M3` / `v1.1`. 마일스톤(M1~M3) 배치는 `ROADMAP.md`.
- 사용자 유형은 모두 가정 구성원이다. MVP에서 가정에 합류한 사람은 전원 관리자(`admin`)다(ACC-06). 별도 표기가 없으면 두 사람 모두 수행할 수 있다.
